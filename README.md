Deploy-Flask-App-with-Nginx-using-Ansible is a simple infrastructure automation project that uses Ansible to configure a local or remote Linux machine to deploy a Python Flask web application behind the Nginx web server. The playbook installs required packages, sets up Python dependencies, configures Nginx as a reverse proxy, and ensures the Flask app is properly launched and served. This project demonstrates practical use of Ansible for deploying lightweight web applications and is ideal for beginners learning DevOps automation and provisioning.
